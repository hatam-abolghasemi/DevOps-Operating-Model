# Security Policy

Open Kitchen is documentation plus the GitHub Actions workflows that lint and release it. Security issues here mostly mean those workflows, the release process, or a link that points somewhere harmful.

## Supported versions

Only the latest release and `main` get fixes.

## Reporting a vulnerability

Don't open a public issue. Report it privately through [GitHub private vulnerability reporting](https://github.com/hatam-abolghasemi/open-kitchen/security/advisories/new).

Include what you found, where, and how to reproduce it. You'll get a reply within 7 days, and credit in the advisory if you want it.
